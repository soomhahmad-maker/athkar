# موقع أذكار الصباح والمساء 🕌

موقع عربي أنيق لأذكار الصباح والمساء بالأدلة الصحيحة مع مصادرها ودرجة الحديث.

🌐 **الموقع منشور على:** `https://soomhahmad-maker.github.io/athkar/`

## المميزات
- ✅ أذكار صحيحة بمصادرها (البخاري، مسلم، أبو داود، الترمذي...)
- 🔠 خط ثمانية (Sans + Serif Display + Serif Text)
- 🔍 بحث فوري + شريط تقدم + إخفاء المنجز
- 📿 مسبحة دائرية لكل ذكر متعدد + مسبحة عامة
- 🔠 تكبير/تصغير حجم الخط (80% – 160%)
- 🌙/☀️ وضع ليلي ونهاري (يتبع النظام + حفظ الاختيار)
- 💾 حفظ التقدم في المتصفح فقط (localStorage)

## التشغيل محلياً
افتح `index.html` مباشرة في المتصفح — لا يحتاج خادماً.

## النشر (GitHub Pages)
الموقع ستاتيكي بالكامل (HTML + CSS + JS) ويُنشر من جذر فرع `main`.
